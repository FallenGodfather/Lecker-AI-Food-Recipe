# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2025-10-24

### Added
- Initial release of **Lecker** Recipe Recommendation Agent
- **Bilingual support** - English and German
- Language toggle button for instant switching
- Three-question conversational interface
- AI-powered recipe recommendations
- TheMealDB API integration
- Cross-platform support (iOS, Android, Desktop)
- **Smooth UI animations**:
  - Fade in/out effects
  - Scale animations on button press
  - Staggered card appearances
  - Loading screen with pulsing animation
- **Modern UI design**:
  - Rounded corners on buttons and cards
  - Better color scheme
  - Improved spacing and layout
  - Custom RoundedButton component
- Input validation and error handling
- Web links for full recipe details
- Restart functionality

### Features
- Bilingual interface (English 🇬🇧 / German 🇩🇪)
- Questions about cuisine, dishes, and flavors
- Personalized recipe recommendations
- Top 10 matches with web links
- Graceful error handling
- Loading states during API calls
- Mobile-optimized interface
- Smooth animations throughout

### Technical
- Built with Python and Kivy
- LanguageManager for translations
- Custom RoundedButton widget
- Animation API for smooth transitions
- requests library for API calls
- Buildozer configuration for Android
- MIT License
- Comprehensive documentation

### UI/UX Improvements
- Rounded buttons with hover effects
- Card-based recipe display
- Better visual hierarchy
- Smooth transitions between screens
- Improved error messaging
- Language-specific hints and examples
